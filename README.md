Realización del trabajo práctico número 1 de la materia Aprendizaje Automático de la tecnicatura universitaria en inteligencia artificial.\
El trabajo consta del análisis del dataset "house-prices.csv" para poder predecir los precios de las casas mediante el uso de modelos de regresión lineal.\
Para llegar a nuestro objetivo hacemos uso de la librería scikit-learn y descenso_gradiente.py para los modelos de regresión lineal, además utilizamos pandas y numpy para el manejo del dataset y matplotlib y seaborn para los gráficos.
